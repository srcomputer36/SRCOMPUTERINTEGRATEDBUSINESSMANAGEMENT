# নূরানী বাংলা শিক্ষা — হাতের লেখা অনুশীলন খাতা

"নূরানী বাংলা শিক্ষা — নার্সারি (শিশু শ্রেণি)" (নূরানী তা'লীমুল কুরআন বোর্ড বাংলাদেশ)
বইয়ের পাঠক্রম অনুসারে ছোটদের হাতের লেখা অনুশীলনের জন্য প্রিন্টযোগ্য A4 PDF তৈরির স্ক্রিপ্ট।

* `output/Nurani_Bangla_Hater_Lekha_Khata.pdf` — রেডি PDF (৩৩ পৃষ্ঠা)
* `make_worksheets.py` — জেনারেটর
* `fonts/` — Hind Siliguri ও Noto Sans Bengali (SIL Open Font License)

## চালানো

```bash
pip install pymupdf
python3 make_worksheets.py --name "আপনার মাদরাসার নাম" --address "ঠিকানা, মোবাইল"
# ঘরের আকার বদলাতে (সেমি):
python3 make_worksheets.py --name "..." --box 2.3
```

## পাতার বিন্যাস

1. **পৃষ্ঠা ১** — প্রচ্ছদ + পুরো পাঠ-পরিকল্পনা/সূচি (কোন দিন কী লেখাবেন)
2. **প্রথম পাঠ** — স্বরবর্ণ (৪ পাতা), ব্যঞ্জনবর্ণ (১০ পাতা) → খালি ঘর
3. **দ্বিতীয় পাঠ** — বানান করে পড়ি (৩ পাতা) → দুই-লাইন খাতা
4. **তৃতীয় পাঠ** — স্বরচিহ্ন, কা-কি-কী-কু-কূ, আ-কার শব্দ (৯ পাতা)
5. **চতুর্থ পাঠ** — সাত দিন, বারো মাস, গাছের নাম (৪ পাতা)
6. **অতিরিক্ত** — খালি ঘর ও খালি দুই-লাইন পাতা (২ পাতা)

প্রতিটি পাতায়: প্রতিষ্ঠানের নাম, ছাত্রের নাম/রোল/তারিখ/বার/শিক্ষকের স্বাক্ষর ঘর,
আজকের লেখার নমুনা, এবং নিচে অভিভাবকের স্বাক্ষরের জায়গা।
